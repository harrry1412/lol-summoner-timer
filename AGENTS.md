# Project instructions

This is a React+Typescript+Vite project

## Development Rules

Use React and Typescripts
Keep components simple and readable
Do not add new dependencies without asking first
Make small, focused changes
Explain important changes after editing
Run 'npm run lint' after modifying code
Do not modify unrelated codes
Do not run git commands, leave all git operations to the developer

## Project Goal

Build an IPad friendly League of Legends summoner spell timer
The application should be frontend-only for now
